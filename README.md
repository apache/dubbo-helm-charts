The project is the official Chart repository for all applications, maintained by the Apache Kdubbo official team.

## Usage
Helm must be installed to use the charts. Please refer to Helm's documentation to get started.

Once Helm is set up properly, add the repository as follows:

```bash
helm repo add dubbo https://charts.dubbo.apache.org
helm repo update
```

You can then run `helm search repo dubbo` to see the charts.
